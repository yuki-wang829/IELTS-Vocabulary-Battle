# Silvia · Shinan IELTS

Silvia 的雅思阅读个人网站，包含教师资历、阅读学习介绍、学习需求摘要工具及现有词汇对战。

## 本地运行

```sh
npm install
npm run dev
```

## 构建与部署

```sh
npm run build
```

发布目录为 `dist`，可沿用 Vercel 的 Vite 设置。首页位于 `/`，原有双队词汇对战位于 `/vocabulary/`。Vite 配置同时构建两个页面，现有游戏源码保留在 `src/`。

学习需求摘要仅在浏览器中生成，不提交数据。个人照片在 `public/assets/`，资历来自老师提供的介绍素材。

Sites 私有预览和本仓库分别部署。自有域名 DNS 设置由域名服务商管理。

## 学习练习室

`/games/` 提供 5–9 分目标分组的拼写、听音辨词、词义和长难句拆解。题库包含 60 个词与 15 个原创教学例句。12 题自适应词义测试逐题升降难度（范围 5–9），末题后的难度用于推荐练习组，不预测雅思成绩。生词及测试建议使用本机 localStorage；发音使用设备 Web Speech 英语语音，不录音、不做发音评分。
